## 用 VS Code 连接后的操作

在 VS Code Remote-SSH 终端中执行：

```bash
cd ~
git clone https://github.com/yu20120707/CrushPilot_Terra.git
cd CrushPilot_Terra/deploy
```

将本地 `deploy/.env` 上传/复制为服务器上的 `deploy/.env`，然后务必将 `POSTGRES_PASSWORD` 改成高强度随机密码。

```bash
docker compose up -d --build
docker compose ps
curl --fail http://127.0.0.1:8080/ready
```

首次部署时，`corpus-publisher` 会自动完成全量 Source Manifest、Markdown
Chunk、中文 FTS、Embedding 和原子发布；成功后后端才会启动。原始资料只会
以精排选中的 Chunk 进入在线提示词，不会整篇注入。

```bash
docker compose logs corpus-publisher
docker compose exec backend python /app/scripts/verify_source_coverage.py \
  /data/corpus-artifacts/source-manifest.yaml
```

浏览器访问：`http://43.138.155.193:8080`。

## 切换模型

编辑 `deploy/.env` 后重启后端服务：

```bash
# 使用 DeepSeek
MODEL_PROVIDER=deepseek

# 使用 Longxia
MODEL_PROVIDER=longxia

docker compose up -d --force-recreate backend
```

切换 Embedding 模型或修改知识源时，必须同时递增 `CORPUS_VERSION`，再运行
`docker compose up -d --build`。旧发布版本会保留一版用于回滚；不要直接
更新生产知识表。

部署前，在腾讯云安全组放行 TCP `8080`。如果后续绑定域名并启用 HTTPS，放行 TCP `80`、`443`，且反向代理必须对 `/api/v1/chat` 关闭响应缓冲。
