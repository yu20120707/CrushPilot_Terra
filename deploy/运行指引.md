# CrushPilot 本机运行指引

## 前置条件

- Windows + Docker Desktop
- `deploy/.env` 已填写模型配置和 PostgreSQL 密码；从 `.env.example` 复制生成，不能提交密钥。

## 启动前后端

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\start.ps1
```

脚本会启动 Docker Desktop（如未运行）、启动 PostgreSQL、语料发布器、后端和前端，并等待后端健康。

首次运行或代码更新时使用构建模式：

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\start.ps1 -Rebuild
```

首次构建会准备语料和下载模型，可能需要数分钟。完成后访问：

- 前端：<http://[::1]:8080/>
- 就绪检查：<http://[::1]:8080/ready>

本机若 `localhost:8080` 指向其他程序，请使用上面的 IPv6 地址。

## 常用命令

```powershell
cd .\deploy
docker compose --env-file .env ps
docker compose --env-file .env logs -f backend
docker compose --env-file .env down
```

如镜像拉取报 Docker Hub `EOF`，先执行：

```powershell
docker desktop restart
docker pull python:3.13-slim
```

然后重新运行 `start.ps1`。
