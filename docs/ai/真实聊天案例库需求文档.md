# 真实微信聊天案例库 PRD

## 目标

用户提供微信聊天截图，沉淀为经过本人确认的高质量案例。CrushPilot 在相似场景下参考案例的语气和处理方式，生成新回复；不照抄原聊天。

## 一期范围

输入为单张或多张按时间顺序排列的微信聊天截图。

流程：

`上传截图 → OCR 提取 → 用户校正与脱敏 → 标记好回复 → 审核入库 → 相似问题检索参考`

每个入库案例至少包含：

| 字段 | 说明 |
|---|---|
| 对方原话与必要上下文 | 用于判断场景，非整段无关聊天记录 |
| 认可的回复 | 用户确认“这句好”或手动修改后的版本 |
| 场景标签 | 如回复慢、邀约、争吵、边界、暧昧期 |
| 可选说明 | 这句为什么好、不能碰的点 |
| 审核状态 | 草稿 / 已批准 / 拒绝 |

## 需求

1. 截图可预览，OCR 后的文字必须允许用户修改。
2. 入库前必须展示脱敏预览；姓名、头像、微信号、手机号、地址等不进入案例库。
3. 用户可选择某条回复作为“好回复”，也可自行编辑。
4. 只有“已批准”的案例才允许参与线上检索。
5. 回答时仅学习案例的语气、节奏和边界，不展示、复述或照抄原案例。
6. 不收录操控、跟踪、施压、欺骗、性越界或未成年人相关案例。

## 不做什么

- 不直接微调模型。
- 不把全部聊天记录自动入库。
- 不自动判定一条回复是否高质量。
- 不向其他用户暴露任何原始截图或案例文本。

## 验收

- 20 条脱敏截图可完成“提取—编辑—批准”闭环。
- 相似提问能召回已批准案例；不相关提问不应召回。
- 人工盲评中，新回答不复述案例原句，且语气自然、边界安全。
- 删除或撤销批准后，案例不再参与线上检索。

## 风险

- 截图 OCR 会错字或漏上下文，必须由用户校正。
- 真实聊天含隐私，默认不入库，必须显式批准。
- 单个案例不代表通用策略，检索结果只能作为参考。
