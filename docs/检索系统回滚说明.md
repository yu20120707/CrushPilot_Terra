# 检索系统回滚说明

Corpus 发布保留当前版本和上一已发布版本。回滚前会重新检查目标版本的
approved Chunk 与匹配的 Embedding 是否完整；损坏版本会安全失败。

```powershell
py scripts/rollback_corpus.py 2026.06.1 `
  --database-url $env:DATABASE_URL
```

回滚后：

1. 将部署配置的 `CORPUS_VERSION` 改为目标版本；
2. 重启后端；
3. 确认 `/ready` 为 200 且 `corpus=true`；
4. 回放拒绝、边界、无证据和 SSE 关键场景；
5. 记录回滚原因、Trace ID 和指标变化。

禁止把已删除的旧 JSON 向量、硬编码文档路由或完整 Markdown 注入作为回滚
路径。若数据库不可用，应恢复数据库服务或已保留的 Corpus，而不是伪正常回答。
