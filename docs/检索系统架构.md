# CrushPilot 检索系统架构

本实现以
[`CrushPilot_检索系统与Skill_Runtime_技术设计_v1.0.md`](../CrushPilot_检索系统与Skill_Runtime_技术设计_v1.0.md)
为基线。在线链路固定为：

```text
ConversationContext
→ SceneAndRetrievalPlan
→ PostgreSQL FTS + pgvector exact cosine
→ Weighted RRF
→ Cross-Encoder Rerank（故障时保留 RRF）
→ Diversity / Parent / Neighbor
→ Evidence Gate
→ Selected Chunk Prompt
→ ChatResult validation
```

## 运行边界

- `skill.yaml` 是唯一策略源；`skill.compiled.json`、Hash、版本或必需场景不一致时 readiness 失败。
- 生产模式只使用已发布 PostgreSQL Corpus。数据库、Corpus 或模型配置不就绪时 `/ready` 返回 503，聊天返回 503。
- 正常在线请求只有两次生成式模型调用：场景/检索计划和最终回答。Embedding 与 Reranker 不属于生成式调用。
- 无证据是正常业务状态；系统会给 Skill-only 保守建议。索引或版本故障是系统异常，不能回退旧链。
- Trace 默认只保存枚举、ID、Hash、分数、版本和阶段耗时，不保存完整用户原文或候选正文。
